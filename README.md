# 🧁 EIQUEKIES - Premium Bakery Management PWA

Aplikasi pengurusan kedai kek & bakery premium bertaraf produksi.

## 🚀 Teknologi
- **Frontend:** HTML5, CSS3, Vanilla JS (PWA)
- **Backend:** Cloudflare Workers REST API
- **Database:** Cloudflare D1 (SQLite)
- **Hosting:** Cloudflare Pages / Workers Assets
